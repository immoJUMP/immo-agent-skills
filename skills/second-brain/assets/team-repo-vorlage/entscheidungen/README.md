# Entscheidungen

Eine Datei je Entscheidung: `JJJJ-MM-TT-slug.md` nach [_vorlage.md](_vorlage.md). Die Entscheidung erklärt das Warum; die Regel, die daraus folgt, steht an genau einem Ort (`team/`, `agenten/<slug>/regeln.md` oder `wissen/`) und verweist hierher.

Überholte Entscheidungen werden nicht gelöscht. Sie bekommen den Status „ersetzt durch“ mit Link auf die neue. Freigabe: nur Eigentümer. Was nur die Geschäftsführung sehen darf, liegt in `geschaeftsfuehrung/entscheidungen/`.
