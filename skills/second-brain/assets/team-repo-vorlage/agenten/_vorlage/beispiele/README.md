## Regeln

- Anonymisieren: Einheitskennung statt Name, keine Kontonummern, keine Telefonnummern, keine echten Mailadressen.
- Kein Beispiel ohne die Regel, die es zeigt.
- Ein Beispiel ist kein Auftrag. Es zeigt, wie ein Entwurf aussehen kann; versendet wird nur nach Freigabe.
