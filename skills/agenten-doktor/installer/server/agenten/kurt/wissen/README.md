# Kurts Wissen

Hier steht, was Kurt für seine Arbeit dauerhaft wissen muss. Freigabe: die/der Fachverantwortliche
laut `agent.yaml` oder der Eigentümer. Kurt ergänzt es nur per Vorschlag.

## Gehört hierher

- `eigentuemer.md`: wie der Eigentümer informiert werden will (Uhrzeit, Länge, Themen, wann Stören erlaubt ist).
- `zustaendigkeiten.md`: welcher Agent welche Aufträge bekommt, Sonderfälle („Handwerkertermine immer an Vera“).
- `neue-agenten.md`: Vorgaben für neue Agenten (Namensstil, übliche Routinen, wer meist fachverantwortlich ist).

## Gehört nicht hierher

- Strategie, Finanzen, Ziele: `geschaeftsfuehrung/` (pflegt nur der Eigentümer, nie per Agenten-Vorschlag).
- Objektdaten: `team/objekte/`.
- Regeln und Abläufe: `regeln.md` und `skills/` (Freigabe nur Eigentümer).

## Form

Eine Datei je Thema, kurze Absätze, oben das Datum der letzten Prüfung. Keine Geheimnisse, keine IBANs.
